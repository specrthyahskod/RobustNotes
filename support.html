Frequently asked questions

Search topics or open a question to see steps.

How do I install RobustNotes on Windows?

Download the Windows setup file from the download page, open it, and follow the installer prompts. If Windows shows a security prompt, confirm that you downloaded the installer from the official RobustNotes website or GitHub release page.

To update an existing installation, use the app’s update check or install the latest setup package. Your locally stored workspace is kept during a normal in-place update.

Why do I need to sign in, and can I stay signed in?

Desktop profiles are local to this device. On Windows, select Keep me signed in on this Windows account on the sign-in screen to remember your sign-in securely for that Windows account. You can lock the workspace from the profile menu when you want to require sign-in again.

Where are my notes and profile data stored?

The desktop app stores profiles and workspace files locally on the computer. RobustNotes does not currently sync desktop notes to a RobustNotes cloud. Use the app’s backup/export tools to keep a separate copy. See the privacy page for more detail.

Why isn’t handwriting OCR ready immediately?

Desktop handwriting recognition is optional. It requires the OCR packages and model files, which are not bundled with the standard Windows installer. Once installed, recognition runs locally. Review the recognized text before saving or replacing ink because handwriting can be misread.

If the OCR model fails to download or load, email support with the full error text and whether you’re using the standard or OCR-enabled setup.

What does RobustNotes AI need?

The desktop AI sidebar needs a compatible model service configured in the app. It can use page text, OCR text, PDF text, and a page image as context. The question and selected context are sent to the endpoint you configure; check whether that endpoint is local or remote before sharing private notes. RobustNotes does not currently ship its own trained model.

How do I use voice input?

Open the AI sidebar, allow microphone access if Windows asks, and use the voice control to capture a question. Speech transcription requires the optional local speech-recognition package and model. If the voice control is unavailable, check the microphone selected in Windows and whether the optional speech component is installed.

How does the music feature work?

The desktop music player can connect to a Funkwhale server that you configure, or play audio files added from your device. For streaming, enter a server address and the account details required by that server, connect, then search its available library. Availability and playback depend on that server and its library.

What works in the Android preview?

The experimental Android preview currently focuses on local text notes and basic search, creation, editing, and deletion. Desktop features such as the drawing canvas, PDF annotation, OCR, AI chat, and whiteboards are not all available on Android yet.

What should I send when the app crashes?

Include the app version, Windows version, whether you installed from the website or updated in-app, what you were doing just before the crash, and the complete error message or crash log if available. Please remove passwords and private note content from screenshots or logs.

What to include

For a bug report, these details usually make it easier to reproduce the problem:

  • App version and Windows or Android version
  • Steps that lead to the issue
  • What you expected and what happened
  • Full error text or a screenshot with private details hidden
