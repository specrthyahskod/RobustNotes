Recognition and assistance

From handwritten page
to useful answers.

Optional local handwriting OCR and page-aware AI help turn notebook content into something you can search, review, and study.

Handwriting OCR

Recognize, review, and replace.

The optional OCR pipeline prepares the notebook page, separates ink into line crops, and recognizes text with the TrOCR handwritten model. Results open in an editable cursive-style review so you can fix misread words.

  • Save corrected text with the page so workspace search can find it.
  • Select ink with the lasso before recognition to replace those strokes with editable cursive-style text.
  • Run inference locally after installing the optional OCR packages and downloading the model.
Handwriting varies, so OCR can make mistakes. Review the result before saving or replacing ink. OCR dependencies and model weights are not bundled with the base Windows installer.
RobustNotes AI

Ask about the page you’re on.

Ask a question about the current page or imported PDF. RobustNotes AI can use saved OCR text, extracted PDF text, recent chat, and a snapshot of the page as context. Voice input can transcribe a spoken question locally when its optional speech model is installed.

  • Get answers grounded in your notes, with uncertainty called out when context is unclear.
  • Generate simple study cards from recognized or extracted text.
  • Keep the chat sidebar hidden until you need it.
The current desktop build connects to a local Ollama-compatible endpoint. RobustNotes’ own trained model is not included yet. Requests stay on-device when the endpoint and model are local.
Private by default

Your notes stay yours.

RobustNotes is designed to keep your everyday work on your computer, with clear choices when a feature needs an external service.

Local-first, by design

Create a local profile and keep its workspace on your device. There is no required online account or built-in cloud sync.

  • Each local profile has a separate workspace on the device.
  • Make password-encrypted backups and choose where to store them.
  • Optional handwriting OCR runs locally after its model is downloaded.
  • AI context is sent to the local Ollama-compatible service configured in the app.

A few useful details

Before you get started.

Is RobustNotes free?

Yes. This beta is free to download. The project source is available on GitHub.

Where are my notes stored?

Profiles and documents are stored locally on this Windows device. RobustNotes does not currently provide cloud sync, so use the encrypted backup feature if you need a separate copy.

Does handwriting OCR work immediately?

OCR is optional. Its Python packages and handwriting model are not included in this base Windows bundle. When enabled in a development setup, the model downloads on first use and recognition runs locally.

What does the AI feature need?

The current desktop build needs an Ollama-compatible service running locally. It sends the question, recent chat, current page context, and page image to that local service. RobustNotes does not include its own trained SLM yet.

Can I use it on Linux or Android?

The Python desktop app can be built on Linux. The Android app currently supports local text notes with search, create, edit, and delete; it does not yet include the desktop drawing canvas, PDF tools, handwriting OCR, AI chat, or whiteboards.

How do I get help?

Email support@robustnotes.com and include your Windows version and a short description of the issue. Please don’t attach private notes unless needed.
